This is especially important when utilising computationally heavy models like Recurrent Neural Networks (RNNs), making it advantageous over simple returns.</li><li><strong>Stationarity</strong>:<br>Log returns tend to have more stable statistical properties (e.g., mean and variance) over time compared to raw prices, making them better suited for modelling and forecasting. When these extrapolated log returns are converted back to prices, the result can lead to <strong>unrealistic exponential growth or decline</strong> in prices, making the predictions less reliable over long horizons.</li></ul><h3>Why This is Problematic</h3><h4>Problem 1:</h4><p>Log returns r(t) describe the proportional change in price:</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/169/1*dg7ls2juKILd4XPv_io87A.png" /></figure><p>Over multiple periods, log returns accumulate multiplicatively:</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/308/1*ZFIJ43dOhX5POOrDO0scng.png" /></figure><p>Prophet cannot naturally handle this compounding effect because it adds the components linearly, which oversimplifies the true dynamics.</p><h4>Problem 2:</h4><p>Additive Formulation Leads to Linear Growth:</p><p>Using Prophet’s trend component g(t), for example:</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/316/1*Lkz__nhOqFG8JAfEnhITMw.png" /></figure><p>Here, k is the base growth rate, and δ adjusts the rate at changepoints. Its ability to handle non-linear trends and incorporate external factors further enhances its robustness, making it a reliable tool for financial forecasting when paired with other models.</p><h3>Model — LSTM</h3><p>LSTM (Long Short-Term Memory) is a type of RNN designed to effectively learn from sequential data by addressing the vanishing gradient problem in traditional RNNs. Unlike standard RNNs, LSTMs use a memory cell and gates (input, forget, and output) to regulate the flow of information, allowing the network to retain long-term dependencies. This makes LSTMs ideal for tasks like time series forecasting, where understanding temporal relationships is crucial.</p><p>LSTM networks are utilized to forecast SPY’s future returns by capturing long-term dependencies in the time series data. LSTMs are well-suited for this task because they can effectively model the sequential patterns in SPY’s while mitigating issues like the vanishing gradient problem. By leveraging the network’s memory and gating mechanisms, the model aims to generate reasonable predictions of SPY’s long-term trends.</p><h3>The LSTM Architecture</h3><p>The Long Short-Term Memory (LSTM) network is designed to learn both short-term and long-term dependencies in sequential data, such as SPY’s historical log returns. Its architecture consists of a <strong>memory cell</strong> and three gates that regulate the flow of information at each time step:</p><h3>Internal Mechanisms</h3><ol><li><strong>Forget Gate (Fₜ)</strong>: Decides which information to discard from the previous memory state using a sigmoid activation function:</li><li><strong>Input Gate (Iₜ)</strong>: Determines which new information to add to the memory cell by combining a sigmoid function (to decide what to update) and a tanh function (to decide how much to update)</li><li><strong>Output Gate (Oₜ)</strong>: Controls the output by filtering the updated memory state (Cₜ) through a tanh function and scaling it with a sigmoid function:</li></ol><h3>Inputs and Outputs</h3><p>The <strong>memory cell</strong> (Cₜ) integrates the forget and input gates to store information over time:</p><p>Finally, the <strong>hidden state</strong> (Hₜ) is derived from the memory cell and the output gate:</p><p>We can have the following interpretation of the hidden state and the cell states.</p><ul><li><strong>Hidden State</strong>: Short-term memory, updated at each step, summarizes the current moment.</li><li><strong>Cell State</strong>: Long-term memory, carries information across the sequence.</li></ul><figure><img alt="" src="https://cdn-images-1.medium.com/max/595/1*BZhP05QEtaEdJ1dS-7rKfQ.png" /><figcaption>Figure 16: LSTM Model Architecture, Credits : <a href="https://d2l.ai/chapter_recurrent-modern/lstm.html">https://d2l.ai/chapter_recurrent-modern/lstm.html</a></figcaption></figure><h3>How the LSTM Learns SPY Data</h3><p>The LSTM model is applied to SPY’s historical log returns to predict future returns by processing sequences of data and capturing temporal dependencies. The architecture described above ensures the model can focus on both short-term fluctuations and long-term trends.</p><p>The dataset consists of 373 monthly data points representing SPY’s log returns. To train the LSTM, we split the data into overlapping sequences, each containing 120 consecutive time steps X₁, X₂, …, X₁₂₀.</p><p>The choice of a sequence length of 120 for this LSTM Model due to the need to capture meaningful temporal patterns in SPY’s monthly log returns while balancing computational efficiency.</p><p>These sequences are fed into the LSTM as input, acting as sliding windows over the data.</p><p>For example:</p><ul><li>The first sequence contains data points X₁ to X₁₂₀ ,</li><li>The second sequence contains X₂ to X₁₂₁, and so on.</li></ul><p>Each sequence is paired with a target value y, representing the log return immediately following the sequence X₁₂₁ , X₁₂₂ etc.). This setup uses a sliding window approach, where the model leverages the past 120 log returns in the sequence to predict the next log return. By processing overlapping windows, the LSTM learns how historical patterns influence future returns.</p><h3>Processing Through Layers</h3><p>The model is configured with two LSTM layers (num_layers = 2).</p><p>The two-layer structure enables the model to learn at different levels of abstraction:</p><ul><li>The <strong>first layer</strong> captures simple temporal dependencies, such as month to month fluctuations.</li><li>The <strong>second layer</strong> identifies more abstract and long-term patterns, such as trends over multiple months.</li></ul><p>Two layers strike a balance between model complexity and computational efficiency, avoiding overfitting while capturing meaningful patterns in the SPY data.</p><p><strong>First Layer</strong>:</p><ul><li>The <strong>first LSTM layer</strong> processes the input sequence one time step at a time. For each time step t, it passes the values of the sequence through all of the gates and outputs the hidden states and the cell states.</li><li>The first layer outputs a sequence of hidden states H₁, H₂, …, H₁₂₀, summarizing the learned information at each time step.</li></ul><p><strong>Second Layer</strong>:</p><ul><li>The <strong>second LSTM layer</strong> takes the hidden states from the first layer H₁, H₂, …, H₁₂₀ as input and processes them similarly.</li><li>This layer refines the information from the first layer, extracting higher-level features and long-term dependencies.</li></ul><ol><li><strong>Final Output</strong>:</li></ol><ul><li>The last hidden state (H₁₂₀) of the second layer represents the most refined understanding of the sequence and is used to predict the target value (y).</li></ul><p>Only H₁₂₀, the hidden state from the final time step, is passed to the next layer because it represents a filtered and processed summary of the sequence, capturing both short-term and long-term dependencies. In contrast, C₁₂₀, the cell state, is designed to function as layer-specific long-term memory, internal to the current layer. Each layer independently manages its own cell state to learn patterns at its level of abstraction, ensuring modularity and preventing entanglement between layers.</p><p>In total, there will be 240 cells processing the monthly SPY log returns, with 120 cells dedicated to each sequence length across 2 layers.</p><h3>Why This Works for SPY Data</h3><p>The LSTM’s architecture is ideal for time series data like SPY’s log returns:</p><ul><li>The <strong>forget gate</strong> enables the model to filter out irrelevant historical information.</li><li>The <strong>input gate</strong> allows the model to focus on relevant new information.</li><li>The <strong>memory cell</strong> retains long-term patterns, such as market trends and economic cycles.</li><li>The <strong>two-layer structure</strong> allows the model to refine and abstract patterns across time steps.</li></ul><p>By learning from SPY’s historical log returns, the LSTM uncovers temporal patterns essential for predicting future returns. This approach is particularly effective for financial time series forecasting, where both short-term and long-term dependencies play critical roles.</p><h3>Data and Features</h3><h3>Data Used</h3><p>We use the monthly dataset for the LSTM model, as the daily and weekly datasets are too large and computationally expensive for the available resources. However, the future is uncertain and we want our results to reflect this.</p><p>The goal of this process is to provide a <strong>probabilistic forecast</strong> of log returns by estimating both the most likely trajectory (mean forecast) and the range of possible outcomes (confidence intervals). In a normal Neural Network, MCD shuts off some neurons to change the values of predictions. For LSTM, some outputs in each hidden layer is not passed on to the next, enabling stochasticity. This will then give us a distribution of predictions.</p><p>We can utilise this distribution to obtain a mean forecast and a confidence interval. To ensure that the results are reproducible, we run MCD with a seed of 42.</p><h3>Checking Normality of Data</h3><p>For a Z value to be used, the distribution needs to be normal.
